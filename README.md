This webpage displays a simple tool to calculate “instant matchpoint” results for Richard Pavlicek's published ACBL Instant Matchpoint tournaments.

Only RuderSyv scores are supported as input data for the tournament results.

For the reference scores, use the RBN files as published on RP's website.

This tool was built with Claude Opus 4.1 with minor additions made with GPT-6.

The code is in the public domain.
